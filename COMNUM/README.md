# COMNUM - Comunicaciones Numéricas
## TAF ISC - IMT Atlantique

Este directorio contiene todos los documentos LaTeX del curso de Comunicaciones Numéricas.

### 📚 Contenido

#### Materiales de Estudio
- **`Formulario_COMNUM.tex`** - Formulario completo con 14 secciones:
  - Modulaciones Digitales (BPSK, QPSK, PAM, QAM)
  - Procesos Estocásticos (WSS, cicloestacionarios, ruido filtrado)
  - Filtrado y Conformación
  - OFDM (parámetros, prefijo cíclico, pilotos)
  - Canal y Ecualización (DFE, estimación)
  - Probabilidad de Error
  - Códigos Correctores (Hamming, decodificación por síndrome)
  - Canal Multi-trayecto
  - Doppler y Movilidad
  - Y más teoría práctica para exámenes

- **`Ejercicios_Handbook_COMNUM.tex`** - 17 ejercicios resueltos del Handbook:
  - Procesos Estocásticos (5 ejercicios)
  - Ejemplos de Modulaciones (3 ejemplos)
  - Códigos de Bloque Lineales (5 ejercicios)
  - Canal Multitrayecto y OFDM (2 ejercicios)
  - Códigos avanzados: C(6,3), Hamming(7,4), C(2,5)

- **`Guia_Completa_COMNUM.tex`** - Guía completa del curso (versión 1 columna)
- **`Guia_Completa_COMNUM_2col.tex`** - Guía completa del curso (versión 2 columnas)

1. **Para estudiar teoría**: Usar `Formulario_COMNUM.tex`
2. **Para practicar**: Usar `Ejercicios_Handbook_COMNUM.tex`
3. **Para repasar exámenes**: Revisar los archivos `Sol_*.tex` correspondientes
4. **Guía completa**: Usar `Guia_Completa_COMNUM.tex` o la versión de 2 columnas
