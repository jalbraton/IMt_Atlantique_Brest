# IMT Atlantique Brest - Materiales de Curso

Este repositorio contiene materiales académicos de cursos de IMT Atlantique Brest.

## Estructura del Repositorio

### AIST (Architectures et Ingénierie des Systèmes de Transmission)

Curso sobre arquitecturas e ingeniería de sistemas de transmisión (RF y Óptica).

#### Contenido

- **Examenes/**: Enunciados de exámenes y soluciones
  - Enunciados LaTeX de exámenes 2019-2024 (RF y Óptica)
  - Soluciones completas en LaTeX
  
- **Formularios/**: Formularios de referencia
  - Formulario completo de AIST (RF y Óptica)
  - Resumen de teoría del curso

## Compilación de Archivos LaTeX

Para compilar los archivos `.tex`:

```bash
pdflatex nombre_archivo.tex
```

## Estructura de Exámenes

### Parte RF (Radio Frecuencia)
- Enlaces terrestres y satelitales
- Bilanes de enlace (link budget)
- Arquitecturas de receptores (superheterodino, homodino)
- Sistemas HAPS (High-Altitude Platform Station)

### Parte Óptica
- Sistemas WDM/DWDM
- OSNR (Optical Signal-to-Noise Ratio)
- Amplificadores ópticos (EDFA)
- Cables submarinos
- Ingeniería de enlaces ópticos

## Años Disponibles

- **2019**: RF (Globalstar) + Óptica (DWDM)
- **2020**: RF (THz) + Óptica (Ingeniería amplificada)
- **2022**: RF (HAPS) + Óptica (Cable submarino)
- **2023**: Óptica (Sistema submarino 8260 km)
- **2024**: RF (E-band) + Óptica (DWDM metro)
